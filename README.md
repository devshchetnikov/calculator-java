# 🧮 Calculator-Java

A simple console calculator written in Java. This is my very first project as I start learning the language!

## 🚀 Features
The program takes two floating-point numbers (`float`) from the user and simultaneously prints the results of four basic arithmetic operations:
* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)

## 💻 Technologies Used
* **Language:** Java
* **Tools:** `java.util.Scanner` for reading user input from the console
